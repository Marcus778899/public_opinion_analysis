# 情緒標註準則

> 版本：prompt-v5（2026-10-08）
>
> LLM 的 prompt（`src/radar/ml/labeling/prompt.py` 的 `RULES`）、Claude 標註 skill、人工測試集都依這份準則。
> **修改規則時三者同步**：改 `RULES` 並升 `PROMPT_VERSION`，再更新本文件；單元測試會檢查每條規則都出現在本文件。

## 輸出

每篇文章輸出一組 `sentiments`：

- **一筆整篇**（`target = null`）：作者對整篇文章主題的整體情緒
- **零到五筆對象**（`target = 名稱`）：作者明確評論的對象各自的情緒

`polarity` 只有三種：`positive`、`negative`、`neutral`。

## 規則

1. polarity 只能是 positive、negative、neutral。
2. 必須有、且只有一筆 target 為 null 的項目，代表作者對整篇文章主題的整體情緒。
3. 文中被作者明確評論的對象（公司、人物、政黨、政策、產品、股票等）各列一筆，target 用文中出現的名稱；只是被提及、被詢問或被比較而作者沒有評價的對象不要列。沒有明確評論的對象就只輸出整篇那一筆。最多列 5 個對象，同一對象只列一次。
4. 判斷的是作者的態度，不是事件本身的好壞：轉述壞消息但作者沒有表態 → neutral。
5. PTT 常見反串與酸文：字面稱讚但語氣明顯諷刺（例如「真是太棒了呢」搭配負面事實）→ negative。
6. 純提問、求助、徵才或交易資訊、新聞轉貼且作者沒有評論 → neutral。
7. 標題為 [新聞] 的文章，只依作者的「心得/評論」段落判斷；沒有該段落或內容空白 → 整篇 neutral。
8. 心得若用帶評價的字眼（例如「慘敗」「被打爆」「笑死」）描述事件或對象，視為作者表態，整篇與該對象都依字眼的語氣判斷；只是中性地摘要新聞 → neutral。
9. 轉貼他人的貼文、聲明或發言（例如 [爆卦] 轉貼臉書文）時，被轉貼者的立場不是作者的立場；作者沒有另外評論 → 整篇 neutral，也不列對象。
10. 只依標題與內文判斷，不參考推文。
11. 提問文（[問卦]、[請益] 等）：真心發問、求助、求推薦 → 整篇 neutral，文中被評價的對象照樣列出；反問、借問題酸人或嘲諷（問題本身就是表態，作者不期待真的得到答案）→ 依規則 5 判斷語氣。
12. 對象沒有指名（用暗語、代稱，例如「某位愛蓋章的公子」「某族群」）→ 整篇依語氣判斷，不列對象；文中直接使用的綽號或代稱（例如「洋流」「泡麵頭」）算指名，照規則 3 列出。
13. 心得或內文只有表情符號、一兩個字，看不出態度（例如「12年前 =.=」「穩了」）→ 整篇 neutral。

## 範例

| 文章 | 整篇 | 對象 | 依據 |
|---|---|---|---|
| [新聞] 7-Eleven 進軍印度慘遭夾殺；心得：「7-11在印度慘敗、被當地雜貨店打爆」 | negative | 7-Eleven: negative | 規則 8：「慘敗」「打爆」是評價字眼，視為表態 |
| [新聞] 中國太陽能企業虧損；心得：「需求下跌、產能過剩，投資相關類股要注意風險」 | neutral | （無） | 規則 8：中性摘要並提醒風險，沒有評價字眼 |
| [新聞] 鴻海員工分紅入帳；心得：「海邊讚讚讚 越南幣？ 人人有機會百萬 各個沒把握」 | negative | 鴻海: negative | 規則 5：「讚讚讚」搭配「越南幣？」「各個沒把握」是酸文 |
| [新聞] 台積電法說營收創新高；心得：「這種公司也能叫護國神山，真是笑死，散戶繼續接刀吧」 | negative | 台積電: negative | 規則 5：反串 |
| [新聞] 派拉蒙併購華納兄弟；文末只有新聞連結 | neutral | （無） | 規則 7：沒有心得段落 |
| [問卦] 竹北遠百要怎麼去 | neutral | （無） | 規則 6：純提問；竹北遠百只是被詢問，依規則 3 不列 |
| [爆卦] 轉貼某政治人物的臉書文，作者只寫「貼文如下」 | neutral | （無） | 規則 9：被轉貼者的立場不是作者的立場 |
| [心得] 超過 40 歲還在高壓工作，餘生用來養病？ | negative | （視內文） | 作者對自身處境的負面情緒 |
| [問卦] 小時候看《少年賭神》很爽，最近有類似的片嗎？ | neutral | 少年賭神: positive | 規則 11：真心求推薦，整篇 neutral，被評價的對象照列 |
| [問卦] 我國最強的檢察官會怎麼查這案子？ | negative | （無） | 規則 11：反問酸人，問題本身就是表態，依規則 5 |
| [問卦] 聽說某位愛蓋章的公子私下狂求天尊顯靈 | negative | （無） | 規則 12：對象沒有指名，不列對象 |
| [問卦] 希望 1128 全壘打，對面泡麵頭看起來很討厭 | negative | 泡麵頭: negative | 規則 12：文中直接使用的綽號算指名 |
| [新聞] 某候選人專訪；心得只有「12年前 =.=」 | neutral | （無） | 規則 13：看不出態度 |

## 人工標註時的提醒

- 拿不準就選 neutral，並在備註寫下理由；這些案例會回頭用來修準則
- 不要看推文、不要查作者其他文章，只看這一篇的標題與內文

## 修訂紀錄

| 版本 | 變更 | 原因 |
|---|---|---|
| prompt-v2 | 加入規則 7、8（新聞文只看心得段落） | v1 在 15 篇測試中，模型依新聞內容而非作者立場判斷 |
| prompt-v3 | 規則 3 排除只被提及的對象；新增規則 9（轉貼他人貼文） | v2 測試中模型把被詢問的地點、被轉貼者的立場當成作者的評價 |
| prompt-v4 | 規則 8 改為「用評價字眼即視為表態」，整篇跟著字眼的語氣 | 三個模型在 v2、v3 都不遵守「整篇 neutral、對象另判」；改成人與模型都能一致遵守的規則 |
| prompt-v5 | 新增規則 11（提問文分真心發問與反問）、12（未指名的對象不列）、13（只有表情符號或一兩個字 → neutral） | v4 交叉比對（Groq vs Claude，234 篇）一致率 77.8%、kappa 0.595；52 篇不一致中 22 篇是 Groq 依規則 6 把反問酸人的提問文標 neutral、Claude 標 negative；另有未指名對象與心得過短的案例無規則可依 |
