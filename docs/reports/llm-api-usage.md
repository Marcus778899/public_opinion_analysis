## 結論

- 免費方案每天只能標約 170～240 篇；第三階段要 3,000 篇以上，免費方案需要 2.5～3 週

| 每篇輸入 token | 約 800 | 約 1,100 |

## 建議

- **記錄 token 用量**：OpenAI 相容 API 的回應帶有 `usage`（輸入、輸出 token 數），backfill 結束時印出總數與換算費用，之後不必再反推
- **`--per-board` 是「這次每個看板要標幾篇還沒標過的」，不是目標總數**：補標時要指定差額，不能填目標總數（填 1,550 會再多標 1,550 篇）。之前跳過的文章會排在抽樣最前面、多半再次失敗，所以要多抽一些：Gossiping 補標抽 80 篇，其中 23 篇是重抽的失敗文章，最後標成 55 篇
- **Stock**：約 3 天後新文章夠了再補約 114 篇（`--per-board 130` 左右，約 0.15 美元）
- **估算費用時**：以每篇 0.0011 美元計，事前推算（每篇 925 token）低估了約 9%
- **跳過的文章**：重跑多半仍失敗，持續失敗的可改用 Claude（`/label-posts`）補標，或直接排除
- **費用控管**：Groq 帳單已設每月上限 5 美元、1 美元與 3 美元的提醒；超過上限會停用整個組織的 API key 到下個帳單週期，串流標註（S3-08）也會一起停
- **模型下架風險**：`qwen/qwen3.8-27b` 是 Preview Model；下架時改用 Groq 其他模型或 Gemini 備援（`Labeler` 介面可換），換模型後需重新評估與人工測試集的一致率
