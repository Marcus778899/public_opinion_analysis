# PTT 站規與板規：自動化程式條文查核（D-045 前置）

**結論：沒有找到明文禁止「只讀」自動化程式的條文**（站規、Gossiping／Stock／Tech_Job 板規皆無「機器人／爬蟲」禁令）。
但有一則 2026/08/24 站方公告：站方為防濫用測試功能，「許多連線APP因自動連續登入連線，反而會被目前測試之功能阻斷登入」，實驗的自動登入可能被擋或鎖定，需甲方判斷。
